# Component Specification: Badges & Status Pills

- **`AppStatusBadge`**: Small pill (`AppRadius.sm = 8px`) displaying a state label and accompanying icon.
- **Background**: 10–12% alpha opacity of the assigned status color.
- **Border**: 30% alpha opacity of the assigned status color.
- **Typography**: `labelMedium` (12 pt, Medium).
- **Text & Icon Color**: Darkened tone of the assigned status color for full contrast readability.
