# Component Specification: Buttons

- **Primary Buttons (`FilledButton`)**: Primary Teal (`#0F766E`) background with `#FFFFFF` text. Used for main form submissions and primary actions. Height: `48px`.
- **Secondary Buttons (`OutlinedButton`)**: Outline border (`outlineVariant`) with Secondary text (`#475569`). Used for secondary or cancel actions.
- **Tertiary Buttons (`TextButton`)**: Text only, no border or background. Used for low-emphasis inline links.
- **Destructive Buttons**: Danger Red (`#DC2626`) fill or text.
- **Disabled & Loading States**: Distinct visual feedback with spinner / low opacity.
