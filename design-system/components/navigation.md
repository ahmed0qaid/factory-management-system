# Component Specification: Navigation Elements

- **NavigationBar Theme**: Material 3 Navigation Bar configured via `AppComponentThemes.navigationBar`.
- **Selected Item**: Primary Teal indicator pill with `onPrimaryContainer` icon & label.
- **Unselected Items**: Secondary Slate color with 70% opacity.
- **AppBar**: Flat/Transparent background in light mode, clean surface in dark mode, centered or start-aligned title according to screen standard.
