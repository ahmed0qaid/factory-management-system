# Typography & Text Scaling

## Font Family

- **Arabic**: Cairo (`google_fonts`)
- **English**: Cairo / Roboto fallback
- **Letter Spacing**: `0.0` for Arabic text to prevent letter separation bugs.

---

## Type Scale

| Role | Font Size | Weight | Line Height | Usage |
| :--- | :--- | :--- | :--- | :--- |
| `displayMedium` | 28 pt | Bold (700) | 1.2 | Large numbers / KPI highlights |
| `headlineSmall` | 24 pt | Bold (700) | 1.25 | Screen headers, major totals |
| `titleLarge` | 20 pt | SemiBold (600) | 1.3 | Header greetings, section titles |
| `titleMedium` | 16 pt | SemiBold (600) | 1.35 | Card titles, dialog headers |
| `titleSmall` | 14 pt | Medium (500) | 1.4 | Action item labels, sub-headers |
| `bodyLarge` | 16 pt | Regular (400) | 1.5 | Primary body text |
| `bodyMedium` | 14 pt | Regular (400) | 1.45 | Default description text |
| `bodySmall` | 12 pt | Regular (400) | 1.4 | Captions, secondary timestamps |
| `labelMedium` | 12 pt | Medium (500) | 1.2 | Badges, chips, status pills |
| `labelSmall` | 11 pt | Medium (500) | 1.2 | Micro labels, table headers |
