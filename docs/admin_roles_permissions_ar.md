# أدوار الإدارة والصلاحيات

## القاعدة الأساسية

- لا يوجد تسجيل ذاتي للموظفين.
- الموارد البشرية تنشئ حساب الموظف أو المدير.
- عند أول تسجيل دخول، يجبر النظام المستخدم على تغيير كلمة المرور المؤقتة.
- الموظف يرى بياناته فقط.
- واجهة الإدارة تظهر فقط للحسابات الإدارية.

## الأدوار

| الدور | الكود داخل النظام | الوصف |
|---|---|---|
| الموارد البشرية | `hr_admin` | الإمكانيات المطلقة داخل النظام |
| المدير العام | `general_manager` | إدارة عليا للعرض والاعتماد والمتابعة |
| المدير المالي | `financial_manager` | إدارة مالية للرواتب والسلف والتقارير المالية |
| الموظف | `employee` | استخدام تطبيق الموظف فقط |

## صلاحيات الموارد البشرية

الموارد البشرية لديه الصلاحيات المطلقة:

- إنشاء الموظفين والمديرين.
- تعديل بيانات الموظفين.
- تفعيل وتعطيل الحسابات.
- تحديد الأدوار والصلاحيات.
- إدارة الحضور والدوام.
- إدارة الورديات والجداول.
- إدارة الإجازات والاستئذان.
- إدارة الجزاءات.
- إدارة الرواتب والسلف.
- رفع مستندات الموظفين.
- نشر الإعلانات.
- عرض سجل العمليات.
- عرض وتصدير جميع التقارير.

## صلاحيات المدير العام

- عرض جميع الموظفين.
- عرض ومراجعة الحضور والدوام.
- اعتماد أو رفض الإجازات والاستئذان.
- اعتماد أو مراجعة الجزاءات الإدارية.
- الاطلاع على السلف والرواتب كتقارير إدارية.
- عرض التقارير العامة.
- لا ينشئ حسابات ولا يغير أدوار المستخدمين.
- لا يعدل مسير الرواتب النهائي إلا إذا منحت الشركة ذلك لاحقًا.

## صلاحيات المدير المالي

- عرض الموظفين بالبيانات اللازمة للرواتب.
- إدارة الرواتب ومسيرات الراتب.
- إدارة السلف والأقساط والمتبقي.
- عرض الجزاءات ذات الأثر المالي.
- عرض بيانات الدوام اللازمة لاحتساب الرواتب.
- تصدير التقارير المالية.
- لا ينشئ حسابات الموظفين.
- لا يعدل بيانات الموظف الأساسية.
- لا يدير المستندات أو الصلاحيات.

## صلاحيات الموظف

- تسجيل الدخول فقط، دون إنشاء حساب.
- تغيير كلمة المرور عند أول دخول.
- عرض بياناته الشخصية.
- عرض أيام العمل ومواعيد الحضور والانصراف.
- عرض التأخير والخروج المبكر.
- عرض الساعات الفعلية والمحتسبة.
- عرض الجزاءات الخاصة به.
- عرض الراتب سواء كان صافي الراتب موجبًا أو سالبًا.
- عرض السلف والأقساط والمتبقي.
- طلب سلفة.
- طلب إجازة أو استئذان عند إضافة هذه الشاشة لاحقًا.
