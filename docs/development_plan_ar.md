# خطة تطوير نظام الموارد البشرية

## المرحلة الأولى: نسخة الموظف الأساسية

الهدف: يستطيع الموظف الدخول ورؤية بياناته.

الشاشات:

1. تسجيل الدخول.
2. الرئيسية.
3. أيام العمل.
4. تفاصيل الحضور.
5. الجزاءات.
6. الراتب.
7. السلف.
8. بياناتي.

## المرحلة الثانية: لوحة الإدارة الأساسية

الهدف: الإدارة تضيف الموظفين وتدير الحضور والسلف والجزاءات.

الشاشات:

1. لوحة معلومات.
2. الموظفون.
3. إضافة موظف.
4. الأقسام والمسميات.
5. الورديات.
6. الحضور.
7. الجزاءات.
8. السلف.

## المرحلة الثالثة: الرواتب والتقارير

1. إنشاء فترة راتب.
2. احتساب الراتب.
3. مراجعة الراتب.
4. اعتماد الراتب.
5. كشف راتب PDF.
6. تقرير الحضور Excel.
7. تقرير السلف.
8. تقرير الجزاءات.

## المرحلة الرابعة: الإشعارات والمستندات

1. Firebase Cloud Messaging.
2. إشعارات اعتماد ورفض.
3. مستندات الموظف.
4. إعلانات الإدارة.

## المرحلة الخامسة: التوسّع

2. أكثر من فرع.
